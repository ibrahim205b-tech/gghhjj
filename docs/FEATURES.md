## يحتاج أجهزة أو حسابات أو خدمات خارجية

| الميزة | المنفذ | ما يلزم للتحقق/التفعيل |
|---|---|---|
| الطباعة عبر خدمة أندرويد | 🟡 منفذ (PDF عربي) | تجربة على طابعة فعلية لها إضافة طباعة على أندرويد |
| طابعة حرارية شبكية ESC/POS (TCP 9100) | 🟡 منفذ (تحويل الصفحة لصورة لضمان العربية) | **لم يُختبر على طابعة فعلية**؛ اختبره على طابعتك قبل الاعتماد عليه |
| طابعة Bluetooth / USB | ⏳ | يتطلب إضافة مكتبة اتصال Bluetooth/USB وجهازاً للاختبار. الواجهة `PrinterTarget` جاهزة لإضافتها؛ حالياً يمكن الطباعة عبر خدمة أندرويد إن كانت الطابعة تدعمها، أو مشاركة PDF |
| ربط حساسات المولدة (MQTT/Modbus) | 🟡 البنية: تسجيل الأجهزة، جدول القراءات، واجهة `DeviceAdapter`، عرض القراءات | يتطلب جهاز مراقبة فعلياً وبروتوكوله. **لا توجد أي قراءات افتراضية** |
| بوابة دفع عراقية | ⏳ | يتطلب مزوداً واتفاقية فعلية. لا توجد بوابة وهمية |
| نموذج لغوي خارجي للمساعد | 🟡 واجهة `ExternalLanguageModel` لإعادة الصياغة فقط | يتطلب مفتاح API يدخله المالك؛ الحسابات تبقى محلية. لا مفاتيح في الكود |
| رسائل SMS / إشعارات Push | ⏳ | يتطلب مزود رسائل و Firebase. التنبيهات حالياً داخل التطبيق |
| خادم المزامنة | ✅ مختبر محلياً | استضافة (VPS) مع HTTPS |
| توقيع Release | ✅ مهيأ | أسرار التوقيع في GitHub |

## مؤجل وسبب التأجيل

| الميزة | السبب |
|---|---|
| تطبيق المشتركين المستقل (فواتيري، شكاوى، طلبات أمبير، إشعارات، إعلانات) | يتطلب حسابات للمشتركين على الخادم ونقاط API مخصصة للمشترك وتطبيقاً منفصلاً. المحرك يدعم البيانات اللازمة (الفواتير، الشكاوى مع تصنيف «طلب تغيير الأمبير/صيانة»). هذه أكبر وحدة متبقية |
| واجهة ويب رسومية للوحة المطور | الواجهة البرمجية جاهزة ومختبرة؛ الواجهة الرسومية لم تُبنَ بعد |
| مسح رمز QR بالكاميرا | يولَّد رمز QR لكل مشترك وكل وصل؛ المسح يتطلب مكتبة كاميرا وتجربة على أجهزة |
| تشفير قاعدة البيانات على الجهاز بالكامل (SQLCipher) | البيانات في مساحة التطبيق الخاصة، والنسخ الاحتياطي مشفر، وكلمات المرور مجزأة؛ تشفير القاعدة كاملة يحتاج تبديل مكتبة SQLite واختباراً على الأجهزة |
| صورة العداد / صور الأعطال والشكاوى | الحقول موجودة في قاعدة البيانات؛ الالتقاط يتطلب مكتبة كاميرا وإدارة ملفات |
| خريطة موقع المشترك | خطوط الطول والعرض تُحفظ؛ عرض الخريطة يتطلب مزود خرائط |
