# الترخيص التجاري الدائم

## المبدأ

- الترخيص **دائم**: يمنح حق استخدام النسخة المرخصة دون أي تاريخ انتهاء.
- لا يوجد اشتراك إجباري. انقطاع الإنترنت أو انتهاء خدمة اختيارية **لا يقفل البيانات ولا الوظائف المحلية أبداً**.
- بدون ترخيص: كل الوظائف تعمل لمولدة واحدة. الترخيص يرفع عدد المولدات المسموح.
- الخدمات الاختيارية منفصلة ولكل منها تاريخ خاص داخل الترخيص (`services`)، مثل: `cloud_sync`، `ai`، `sms`، `iot`، `support`. هذه التواريخ لا تؤثر على حق الاستخدام.

## التقنية

- الترخيص = `base64url(JSON) . base64url(توقيع Ed25519)`.
- التطبيق يحتوي **المفتاح العام فقط** (يُمرر عند البناء `--dart-define=LICENSE_PUBKEY`)، لذلك لا يمكن تزوير ترخيص.
- المفتاح الخاص لا يوضع أبداً في المستودع أو التطبيق.
- الترخيص يمكن ربطه بجهاز أو أكثر عبر «رمز التثبيت» الظاهر في الإعدادات.

## إصدار التراخيص

```bash
cd server
dart run bin/issue_license.dart keygen          # مرة واحدة: يطبع SEED خاص + المفتاح العام
# احفظ SEED في مدير كلمات مرور، وضع المفتاح العام في سر LICENSE_PUBKEY في GitHub

LICENSE_SEED_B64=... dart run bin/issue_license.dart issue \
  --customer "اسم العميل" --generators 3 --device INSTALLATION_CODE \
  --service support=2027-12-31
```

أرسل المفتاح الناتج للعميل ليلصقه في **الإعدادات ← الترخيص ← تفعيل ترخيص**.
يمكن أيضاً الإصدار من الخادم: `POST /admin/licenses` (يتطلب `LICENSE_SEED_B64` على الخادم).

## سياسة النقل (مقترحة)

- نقل الترخيص لجهاز جديد: العميل يرسل رمز التثبيت الجديد، ويُصدر له ترخيص جديد بنفس رقم العميل، ويُبطل الجهاز القديم من لوحة الخادم.
- البيانات تنتقل بالنسخة الاحتياطية المشفرة أو بالمزامنة.
