# الاختبارات ونتائجها

> كل النتائج هنا من تشغيلات حقيقية على GitHub Actions أو محلياً، مع رابط التشغيل.
> ما لم يُختبر مذكور صراحة في قسم «ما لم يُختبر».

## 1) طبقات الاختبار

| الطبقة | أين | ماذا تختبر | محرك حقيقي؟ |
|---|---|---|---|
| Backend unit/API (pytest) | `backend/tests/` | المصادقة، رفض الملفات، الحدود، الطابور، المهلة، فشل المحرك، الحذف، التنظيف، مسارات الاختراق، معالجة العربية | لا — محرك اختبار نغمي **داخل tests فقط** للمنطق |
| Backend real engine | `sawti-backend.yml` ← `real-engine` | بناء صورة Docker الإنتاجية، تشغيل SILMA فعلياً، رفع M4A، استنساخ، توليد الجمل الأربع، تنزيل WAV والتحقق منه، Whisper ASR + تشابه المتحدث | **نعم** |
| Engine evaluation | `sawti-engine-eval.yml` | مقارنة SILMA / Chatterbox / XTTS-v2 على 7 نصوص عربية على CPU | **نعم** |
| Flutter unit | `android_app/test/unit_test.dart` | تنسيق، تحقق العنوان، تحويل الأخطاء، التخزين المشفر للمفتاح، استمرار المكتبة بعد إعادة الفتح، آلة حالات التوليد (خادم مُحاكى بعقد API الحقيقي) | لا |
| Flutter widget | `android_app/test/widget_test.dart` | شاشة البداية ← الرئيسية، RTL، التنقل، التحقق من النص، الإعدادات، الوضع الفاتح، المكتبة والحذف، عرض الجهاز اللوحي | لا |
| **On-device E2E** | `android_app/integration_test/` في `sawti-android.yml` ← `e2e` | التطبيق الحقيقي على محاكي Android 14 ↔ الخادم الحقيقي (Docker + SILMA): الميكروفون، الاستيراد، التجهيز، التوليد، التشغيل، الاستمرار، الحذف | **نعم** |
| Live deployment | `sawti-deploy-hf.yml` | اختبار المساحة المنشورة من خارجها | **نعم** (عند إضافة الأسرار) |

## 3) اختبار جودة الصوت بصوتك أنت

لم تُرسل لي عينة من صوتك، فلم أختبر الاستنساخ على صوتك ولم أستخدم صوت أي شخص آخر دون إذن. استُخدمت عينة
الاختبار المرفقة داخل حزمة SILMA (MIT) فقط. لاختبار صوتك:

1. سجّل من التطبيق (أو جهّز ملف WAV/M4A لصوتك 6–8 ثوانٍ مع نصه).
2. شغّل التطبيق مع خادمك وولّد الجمل الأربع، أو من حاسوبك:
   ```bash
   SAWTI_API_KEY=... python sawtiai/tools/smoke_test.py --url https://<space>.hf.space \
       --sample my_voice.m4a --transcript "النص الذي قلته" --out my_results
   pip install faster-whisper resemblyzer soundfile
   python sawtiai/tools/asr_check.py --dir my_results --ref my_voice.m4a
   ```
3. استمع للملفات في `my_results/` — المقاييس الآلية لا تغني عن أذنك في الحكم على الطبيعية والتشابه.
