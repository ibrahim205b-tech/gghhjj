# معالجة النص العربي قبل التوليد

الكود: `backend/app/text/arabic.py` — الاختبارات: `backend/tests/test_arabic.py`.

## المبادئ
1. **لا تغيير للمعنى**: لا حذف لكلمات ولا إعادة صياغة.
2. **الحركات**: لا تُحذف الحركات الموجودة (إلا بطلب صريح `keep_tashkeel=False` لأغراض المقارنة فقط)،
   ولا تضيف هذه الطبقة أي حركات. محرك SILMA نفسه يشكّل النص تلقائياً بنموذج CATT المدرَّب
   (وليس عشوائياً) لأن المحرك صُمم ليعمل هكذا ويتحسن نطقه بذلك؛ هذا خيار في المحرك
   (`force_tashkeel`) وتأثيره مقاس في تقييم المحركات (`silma_no_tashkeel`).
3. **ما لا يُنطق يتحول إلى كلمات** حتى لا يقرأ النموذج رموزاً بشكل غريب.

## التحويلات

| المدخل | الناتج |
|---|---|
| `07700240001` | صفر سبعة سبعة صفر، صفر اثنين أربعة، صفر صفر صفر واحد (رقم هاتف: خانة خانة، مجموعات 4-3-4) |
| `+9647701234567` | زائد تسعة ستة أربعة، ... |
| `22 نوفمبر 2026` | اثنين وعشرين نوفمبر ألفين وستة وعشرين |
| `05/03/2025` | خمسة مارس ألفين وخمسة وعشرين |
| `10:30` | الساعة عشرة والنصف |
| `15%` / `٢٥٪` | خمسة عشر بالمئة / خمسة وعشرون بالمئة |
| `1,250` | ألف ومئتان وخمسون |
| `3.5` | ثلاثة فاصلة خمسة |
| `د. أحمد` | دكتور أحمد |
| `إلخ` | إلى آخره |
| `؟؟` / `!!!` | ؟ / ! |
| `?` `;` `,` (بين كلمات عربية) | ؟ ؛ ، |
| روابط، بريد إلكتروني، `* # _ ~ | < > [ ] { }`، الرموز التعبيرية | تُحذف |
| `&` `+` `$` `€` | و، زائد، دولار، يورو |
| التطويل `ـــ` | يُحذف |
| الأرقام الهندية `٠١٢٣` | تُعامل كأرقام |

علامات الترقيم التي تؤثر على الإيقاع (، . ؟ ! ؛ :) **تُحفظ** لأنها تعطي وقفات طبيعية.

## تقسيم النصوص الطويلة
`split_into_chunks(text, max_chars)`:
1. التقسيم أولاً عند نهايات الجمل (. ! ؟ أو سطر جديد)،
2. ثم عند الفواصل (، ؛ :) إن كانت الجملة أطول من الحد،
3. ثم عند حدود الكلمات — **لا تُقطع كلمة في منتصفها أبداً** (كلمة أطول من الحد تبقى كاملة)،
4. ثم دمج القطع الصغيرة المتجاورة حتى الحد، مع **الحفاظ على الترتيب**.

يولّد الخادم كل جزء على حدة ثم يدمجها بوقفة 250 ملّي ثانية وتلاشٍ قصير (10 ملّي ثانية) لمنع
النقرات، مع تطبيع مستوى الصوت لمنع التشبع. يظهر للمستخدم «الجزء س من ص» أثناء التوليد.

## اللهجة العراقية
لا توجد معالجة خاصة للهجة: الكلمات العراقية (شلونكم، راح، شكو ماكو، هسه، كلش) تُمرر كما هي.
نتائج النطق الفعلية موثقة في `docs/ENGINE_COMPARISON.md` — **دون ادعاء** دعم ممتاز للهجة.
