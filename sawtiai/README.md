# صوتي AI — Sawti AI

> **صوتك... بكلماتك.** تطبيق Android شخصي لاستنساخ صوتك الحقيقي من عينة قصيرة،
> ثم تحويل أي نص تكتبه إلى ملف صوتي بصوتك.

<p align="center"><b>تسجيل/رفع عينة ← تجهيز النسخة الصوتية ← كتابة نص ← «ولّد بصوتي» ← استماع، حفظ، مشاركة</b></p>

---

## مكونات النظام

```
sawtiai/
├── android_app/        تطبيق Flutter (Android أصلي، عربي RTL، داكن/فاتح)
├── backend/            خادم Python + FastAPI + محرك SILMA TTS (Docker)
│   ├── app/            الكود: API، الأمان، الطابور، معالجة الصوت والنص العربي
│   └── tests/          اختبارات الخادم (pytest)
├── tools/
│   ├── engine_eval/    مقارنة المحركات الحقيقية على العربية (CPU) + تقييم Whisper
│   ├── smoke_test.py   اختبار شامل ضد أي خادم حقيقي (محلي أو منشور)
│   └── asr_check.py    التحقق من وضوح الكلام الناتج بالتعرف الآلي على الكلام
├── docs/               DEPLOYMENT, TESTING, ENGINE_COMPARISON, ARABIC_TEXT, API
├── .env.example        أسماء المتغيرات فقط (بلا أسرار)
└── .gitignore          يمنع رفع الصوت والنماذج والأسرار وملفات البناء
.github/workflows/
├── sawti-android.yml      فحص + اختبارات + بناء SawtiAI.apk + اختبار المحاكي مع الخادم الحقيقي
├── sawti-backend.yml      اختبارات الخادم + تشغيل المحرك الحقيقي داخل صورة Docker الإنتاجية
├── sawti-deploy-hf.yml    نشر الخادم إلى Hugging Face Space واختباره من الخارج
└── sawti-engine-eval.yml  مقارنة المحركات على CPU
```

## كيف يعمل

1. **التطبيق** يسجّل صوتك (WAV ‏24kHz أحادي) أو يستورد WAV/MP3/M4A، ويحفظ العينة في التخزين الخاص بالتطبيق.
2. يرفعها إلى **خادمك** عبر HTTPS مع مفتاح وصول خاص. الخادم يفحص الصيغة الحقيقية للملف (ffprobe) والحجم والمدة،
   يحولها إلى الصيغة المطلوبة، ويحلل الجودة (الضوضاء، التشبع، مدة الكلام الفعلي).
3. «تجهيز النسخة الصوتية»: يقتطع المحرك أوضح ~8 ثوانٍ مع نصها ويحفظها كمرجع للاستنساخ (zero-shot؛ لا تدريب).
4. عند «ولّد بصوتي»: يعالج الخادم النص العربي (أرقام، تواريخ، رموز)، يقسمه دون قطع الكلمات، يولد كل جزء بصوتك،
   يدمجها، ويعيد ملف WAV حقيقياً. العملية غير متزامنة (job) مع تقدم «الجزء س من ص».
5. التطبيق ينزّل الملف، يحفظه في **مكتبتي الصوتية** (يبقى بعد إغلاق التطبيق)، ويحذفه من الخادم.
   لا تظهر «تم توليد الصوت» إلا بعد استلام ملف صوتي صالح (يُتحقق من ترويسة RIFF).

## المحرك المختار: SILMA TTS v1

| | |
|---|---|
| المصدر الرسمي | <https://github.com/SILMA-AI/silma-tts> |
| الأوزان | <https://huggingface.co/silma-ai/silma-tts> |
| الترخيص | الكود **MIT**، الأوزان **Apache-2.0** — يسمح بالاستخدام الشخصي (والتجاري) |
| البنية | F5-TTS (Diffusion Transformer)، ‏150 مليون معامل، عربي + إنجليزي |
| الاستنساخ | من عينة **3–8 ثوانٍ** مع نصها، بدون تدريب |
| يحتاج GPU؟ | لا. يعمل على CPU (أبطأ)؛ GPU يسرعه كثيراً |

**المحرك البديل** المدمج في الكود: Chatterbox Multilingual (MIT) — `SAWTI_ENGINE=chatterbox`.

سبب الاختيار ونتائج الاختبار الفعلية على الجمل الأربع المطلوبة والعراقية: **[docs/ENGINE_COMPARISON.md](docs/ENGINE_COMPARISON.md)**.

## تشغيل الخادم

- **النشر المجاني على Hugging Face Spaces** (مستحسن): [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) — يحتاج سرّين في GitHub فقط.
- **محلياً**: `docker build -t sawti-backend sawtiai/backend && docker run -p 7860:7860 -e SAWTI_API_KEY=... sawti-backend`
- التوثيق التفاعلي (Swagger): `https://<خادمك>/docs`

### متغيرات البيئة
انسخ `.env.example` (لا تضع قيماً حقيقية في Git). الأهم: `SAWTI_API_KEY` (إلزامي)، `SAWTI_ENGINE`، `SAWTI_MAX_TEXT_CHARS`.

## تشغيل تطبيق Flutter (للمطورين)

```bash
cd sawtiai/android_app
flutter pub get
flutter test                 # اختبارات الوحدات والواجهة
flutter run                  # على هاتف موصول
# اختياري: تعبئة عنوان الخادم مسبقاً (ليس سراً)
flutter build apk --release --dart-define=SAWTI_DEFAULT_SERVER_URL=https://<user>-sawtiai.hf.space
```

## ربط التطبيق بالخادم
**الإعدادات ← عنوان الخادم ومفتاح الوصول** ← أدخل `https://<user>-sawtiai.hf.space` والمفتاح ← «اختبار الاتصال» ← «حفظ».
المفتاح يُحفظ مشفراً على الهاتف فقط. لتغيير العنوان لاحقاً عدّله من نفس المكان.

## بناء APK وتنزيله

- يُبنى تلقائياً عند كل تعديل عبر **GitHub Actions ← «Sawti AI — Android APK»**.
- التنزيل: GitHub ← **Actions** ← آخر تشغيل ناجح لـ «Sawti AI — Android APK» ← أسفل الصفحة **Artifacts ← SawtiAI-apk**
  (ملف zip يحتوي `SawtiAI.apk` وبصمته SHA-256).
- التوقيع: بدون أسرار توقيع يُوقَّع بمفتاح debug (قابل للتثبيت). لتوقيع Release ثابت راجع
  [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md#توقيع-release) — لا تُرفع أي مفاتيح إلى المستودع.

### تثبيت APK على Android
1. نزّل `SawtiAI-apk.zip` من Actions على الهاتف وفك ضغطه (أو انقل `SawtiAI.apk` إليه).
2. افتح الملف ← اسمح «بتثبيت التطبيقات من هذا المصدر» عند الطلب ← تثبيت.
3. افتح «صوتي AI» ← الإعدادات ← اربط الخادم ← «إنشاء صوتي».

### تحديث التطبيق
نزّل APK الأحدث وثبّته فوق القديم (تبقى بياناتك). يشترط Android أن يكون **بنفس مفتاح التوقيع**؛
لذلك إن أضفت مفتاح Release لاحقاً فستحتاج لإزالة النسخة الموقعة بمفتاح debug مرة واحدة.

## الخصوصية والأمان (ملخص)
- لا ملفات صوت ولا نماذج ولا أسرار في Git أو في APK (`.gitignore` شامل + فحص آلي داخل CI للـ APK).
- HTTPS إلزامي؛ كل مسارات `/api` تتطلب المفتاح؛ مقارنة ثابتة الزمن وتقييد للمحاولات الفاشلة ومعدل الطلبات.
- الخادم لا يسجّل النصوص ولا الأصوات (فقط معرفات ومدد وعدد أحرف).
- الملفات المؤقتة تُحذف بعد المعالجة، والملفات الناتجة بعد التنزيل أو بعد 60 دقيقة. روابط الملفات تتطلب المفتاح.
- أزرار: حذف العينة الأصلية من الخادم، حذف النسخة الصوتية (خادم + جهاز)، حذف كل الملفات المحلية، حذف كل بيانات الخادم.
- النسخ الاحتياطي السحابي لـ Android معطل لبيانات التطبيق كي لا تخرج عينتك من الهاتف.

## حدود الاستضافة المجانية ومتطلبات التشغيل
- Hugging Face CPU Basic: ‏2 vCPU، ‏16 GB RAM، **بدون GPU**، ينام بعد 48 ساعة خمول (الاستيقاظ يستغرق دقائق)،
  والقرص مؤقت (التطبيق يعيد رفع عينتك تلقائياً عند الحاجة).
- التوليد على CPU **بطيء**: انظر الأزمنة المقاسة في [docs/ENGINE_COMPARISON.md](docs/ENGINE_COMPARISON.md).
- متطلبات SILMA: ~2–3 GB RAM، ~2 GB قرص للصورة والأوزان. Chatterbox: ~7.5 GB RAM.
- يمكن استخدام التطبيق **دون أي اشتراك مدفوع**.
