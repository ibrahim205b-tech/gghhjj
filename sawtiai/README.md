# إنجاز | ENJAZ

> **خطوتك اليوم تصنع مستقبلك**

منصة طلابية عراقية مجانية للمتوسطة والإعدادية:
**تطبيق Android للطالب** + **لوحة إدارة مستقلة** + **خلفية سحابية (Supabase)**.
التطبيق يشتغل بدون إنترنت، والمزامنة السحابية اختيارية، والمشرف يتحكم بكل المحتوى من اللوحة بدون تعديل الكود أو إصدار APK جديد.

---

## مكونات المشروع

```
sawtiai/
├── apps/
│   ├── student/     تطبيق الطالب — Flutter (com.enjaz.student)، عراقي RTL، يعمل بدون إنترنت
│   └── admin/       لوحة الإدارة — React + TypeScript + Vite + Tailwind
├── supabase/
│   ├── migrations/  قاعدة البيانات (44 جدول) + RLS + التخزين + النشر المجدول + دوال الإدارة
│   ├── functions/   Edge Functions: send-notifications (FCM)، delete-account
│   ├── seed.sql     الهيكل الدراسي الأولي (يحتاج تحقق — بدون مواد أو أسئلة مخترعة)
│   └── tests/       اختبارات الأمان (RLS) واختبار شامل على Supabase حقيقي
├── docs/            BACKEND_SETUP · DEPLOYMENT · TESTING · ARCHITECTURE
├── .env.example     أسماء المتغيرات فقط
└── .gitignore
.github/workflows/  enjaz-student.yml · enjaz-admin.yml · enjaz-backend.yml
```

## تطبيق الطالب

- **الشاشات:** البداية، التعريف والتسجيل (Google أو بدون حساب)، الرئيسية، جدولي الدراسي (قائمة/تقويم)، موادي (فصول ومواضيع وحالة كل موضوع)،
  المنظم الذكي (يعمل بدون إنترنت وبدون ذكاء اصطناعي مدفوع)، امتحاناتي (عد تنازلي، رسمي/شخصي، الدرجات، الدرجة المطلوبة)،
  بنك الأسئلة (بوقت/بدون وقت، مراجعة، شرح، حفظ، إعادة الأخطاء، السجل)، المكتبة (بحث، فلاتر، تنزيل، مفضلة، قراءة بدون نت)،
  التحفيز اليومي، الأدوات (بومودورو، ساعة إيقاف، حاسبة المعدل والنسبة، ملاحظات، مهام، مصاريف، أهداف، إنجازات، إحصائيات)،
  دليل الجامعات (بمصدر وتاريخ تحديث)، الإعدادات (الملف، الصف/السنة، الإشعارات، المظهر، المزامنة، تصدير البيانات، حذف الحساب).
- **اللغة:** كل النصوص الظاهرة باللهجة العراقية في ملف واحد `lib/l10n/app_ar.arb` (أكثر من 300 نص). المحتوى الرسمي يُعرض كما هو بدون تحويله للهجة.
- **بدون إنترنت:** كل البيانات في SQLite على الجهاز، والتعديلات تُزامن لاحقاً (آخر تعديل يفوز، والحذف ينتقل لبقية الأجهزة).
- **الإحصائيات حقيقية:** كل الأرقام تُحسب من بيانات الطالب، ولا توجد نسب مكتوبة مسبقاً.

## لوحة الإدارة

نظرة عامة، الطلاب (بحث، فلترة، إيقاف وإعادة)، الهيكل الدراسي (مراحل، صفوف، فروع، سنوات، مواد، فصول، مواضيع، مع ترتيب وتفعيل)،
بنك الأسئلة (محرر، صور، نسخ، معاينة، نشر وجدولة، استيراد CSV/JSON مع قوالب وتحقق)، المكتبة (رفع PDF وصور، غلاف، جدولة، استبدال، إحصائيات تنزيل)،
التحفيز اليومي (صورة، معاينة، استهداف)، الإعلانات (صورة، زر، تليجرام، استهداف، تكرار، تأكيد)، تحديثات التطبيق (إجباري/اختياري)،
الإشعارات (FCM لكل الطلاب أو مرحلة أو صف أو فرع أو طالب، جدولة، سجل)، مواعيد الامتحانات الرسمية (برابط مصدر إلزامي)،
الجامعات والقبول، الإعدادات العامة، سجل النشاط، المشرفون.

**الأمان مفروض في قاعدة البيانات (RLS)، وليس بإخفاء الأزرار فقط.** لا يوجد تسجيل عام للمشرفين.

### تنزيل التطبيق

GitHub ← **Actions** ← «ENJAZ — Student app (APK)» ← آخر تشغيل ناجح ← **Artifacts ← ENJAZ-apk**.

### تشغيل محلي للمطورين

```bash
# تطبيق الطالب
cd sawtiai/apps/student && flutter pub get && flutter test && flutter run \
  --dart-define=SUPABASE_URL=https://<ref>.supabase.co --dart-define=SUPABASE_ANON_KEY=<anon>
# لوحة الإدارة
cd sawtiai/apps/admin && cp .env.example .env && npm ci && npm test && npm run dev
# قاعدة البيانات محلياً
cd sawtiai && supabase start
```

## مبادئ لا نتنازل عنها

- لا أسرار في Git أو في التطبيقات: مفتاح `service_role` وحساب خدمة Firebase يوضعان في أسرار Supabase فقط.
- لا محتوى رسمي مخترع: لم تُضَف أي مواد أو أسئلة أو معدلات قبول. المشرف يدخلها مع المصدر.
- لا يُعلَّم سؤال كـ«وزاري» بدون مصدر وسنة، ولا تُعلَّم معلومة قبول كـ«رسمية» بدون تاريخ تحقق.
- التطبيق مجاني، ولا يتطلب أي خدمة مدفوعة ليعمل.
